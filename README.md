# Ferrosift

Interactive Ferrosift concept website with a procedural 3D conveyor, material-flow visualization, and recovery calculator.

Live site: https://gtamerlan.github.io/ferrosift/

## Editing

The complete website is in `index.html`: HTML, inline CSS, and JavaScript. It has no build step or external runtime dependencies. Open it in a browser or serve this folder with `python3 -m http.server 8000`.

GitHub Pages publishes the root of the `main` branch. Changes pushed to `main` update the live site automatically. `.nojekyll` preserves plain static-file publishing.

The initial `index.html` is an unchanged copy of the original `Ferrosift.html` from the ChatGPT conversation “Brainstorm Space Startup Ideas”. Demonstrations and projections are concepts, not measured product performance.
