HOW TO READ THE COMPARISON

Measured where possible.
Unknown where unverified.

These collected recordings are not independent holdouts. Each clip retains its source and exposure history.

Real predictions, ready to inspect

The browser replays predictions computed in advance from Ferrosift’s custom-trained weights and the YOLO11s reference. Both receive exactly the same sampled frames. Clip selection does not trigger live inference.

A score needs verified labels

Unlabeled frames are excluded from scores. No detections means no copper alarms at the frozen threshold; it does not establish an error-free frame. Copper annotation recall counts matched labels, including repeated views of a piece.

A reproducible model comparison

The reference is a reproducible model evaluated on the same images. Annotation results guide model development; physical recovery and throughput are measured in material trials. Architecture differences and training lineage are documented below.
