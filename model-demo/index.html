02 / HOW TO READ THIS

One model.
Two very different tests.

The development result is promising within its source imagery. The independent photos expose a substantial transfer gap.

01

Development, not a held-out claim

1,522 conveyor frames, 7,535 copper and 36,563 steel annotations. The model and operating point were selected using this set. Repeated appearances count as separate annotations, not unique physical pieces.

02

Frozen settings on unfamiliar images

232 independent ConMetal-6 phone photos with 412 copper annotations. The same threshold finds only 8. This diagnostic is a domain-shift check, not a conveyor acceptance test.

03

A research comparison, not a product benchmark

YOLO11s is an internal reference, not a commercial sorter. Counts do not establish production speed, ejection accuracy, safety, or performance at another plant.

Operating point, matching, and image credits

Candidate copper threshold: 0.807333. Reference: 0.910188. Both use common external NMS at 640 px. Saved image boxes show only copper alarms above the frozen threshold; annotated copper is a separate optional overlay. Matching uses IoU ≥ 0.5.

The development selection budget is (steel matches + unmatched copper alarms) / steel annotations ≤ 1%. This is an alarm-burden ratio, not a false-positive rate. Phone-photo steel counts include only galvanized and stainless steel; generic ferrous metal, brass, and aluminium are reported as other classes.

Conveyor imagery: SteelDS a3 — Neubauer, Rauch, Koinig, Tischberger-Aldrian, Pomberger and Rueckert (2026), source dataset, CC BY 4.0. Images recompressed and saved detection overlays added.

ConMetal-6 subset: Diyana Ranasinghe and Mehrdad Arashpour (2026), source dataset, CC BY 4.0. Images recompressed for this demo; derived bounding-box overlays added. Original authors do not endorse Ferrosift.
